## Material r0

### #682 — dematerialize closed CDD cells from HEAD (00:10Z, `kind/process` · `area/cdd` · `area/coherence`)

The framing is precise and worth preserving: **the problem is attention, not storage.** `main`'s working tree materializes ~951 `.cdd/` files / 13 MB of closed-cell process history in every checkout. Those payloads are *already* Git blobs — the defect is that they are *also* present-tense in HEAD, where they are tree-navigation, newcomer-comprehension, agent-context and search noise. "Move to the Git layer" would be a misnomer; the blobs are in Git already. The move is to **stop materializing them in HEAD.**

Target: closed-cell payloads stay as file-native blobs in sealed, `main`-reachable commits (history canonical); HEAD keeps only live cells + a compact current-state projection (`CURRENT.json`) + a historical retrieval index (`INDEX.jsonl`). `.cdd` stops being the memory and becomes the **memory map**. Load-bearing structure:

- A pinned lifecycle with a **seal-before-prune invariant**: `S ≺ D ≺ P` — seal (γ writes closeout + `MANIFEST.json`), decide (δ boundary decision binds S), publish (S must be `main`-reachable), then project/prune (a *descendant* removes the bodies from HEAD). A cell path must not leave HEAD until it is sealed, validated, decided, `main`-reachable, and index-resolved. This explicitly forbids "seal on branch → delete on branch → squash to empty tree → no `main`-reachable payload."
- **Declared** custody: `custody_mode: CONTENT | CHAIN` is a cell field, *not* a consequence of which merge button was pressed. CONTENT = payload survives in a `main`-reachable commit (squash-compatible if complete); CHAIN = original role commits and exact-parent bindings also survive (history-preserving merge, no rebase after review).
- **Projection is derivable, not a second truth:** AC5 requires a clean rebuild from Git history to reproduce `CURRENT.json`/`INDEX.jsonl` exactly, verified by `cn cdd index --check`/`--rebuild`.

Status truth is stated honestly in the issue: **this issue removes nothing.** It is design-first (explore), blocked by #681 (which encodes the first principle — `main` = current state only — in `DOCUMENTATION-SYSTEM.md §5`), canonical only when #681 merges. Not dispatched.
